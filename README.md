Veterinaria Patitas
Descripción

Veterinaria Patitas es un sistema web diseñado para facilitar la gestión y el acceso a los diferentes servicios de una veterinaria.

El sitio permite a los clientes consultar productos, gestionar la información de sus mascotas, solicitar turnos y acceder a otras funcionalidades relacionadas con la atención veterinaria.

Además, cuenta con un sector destinado a la administración del sistema, permitiendo gestionar diferentes aspectos de la página.

Objetivo

El objetivo del proyecto es desarrollar una plataforma web que permita mejorar la organización y facilitar la interacción entre los clientes y la veterinaria.

A través del sistema, los usuarios pueden acceder a los servicios de forma más rápida y organizada, mientras que el administrador cuenta con herramientas para gestionar la información del sitio.

Tecnologías utilizadas
Frontend
HTML5: utilizado para estructurar el contenido de las páginas.
CSS3: utilizado para diseñar y dar estilo a la interfaz.
JavaScript: utilizado para agregar interactividad y funcionalidades dinámicas.
Backend
PHP: utilizado para desarrollar la lógica del sistema y conectar la página con la base de datos.
Base de Datos
MySQL: utilizado para almacenar y gestionar la información del sistema.
Herramientas utilizadas
XAMPP: utilizado como servidor local para ejecutar Apache y MySQL durante el desarrollo.
phpMyAdmin: utilizado para administrar la base de datos.
Visual Studio Code: utilizado como editor de código.
Git: utilizado para el control de versiones del proyecto.
GitHub: utilizado para almacenar el repositorio y trabajar de forma colaborativa.
Requisitos para la ejecución

Para ejecutar el proyecto en un entorno local se requiere:

XAMPP versión 8.0 o superior.
PHP 8.0 o superior.
MySQL 5.7 o superior.
Navegador web actualizado (Google Chrome, Microsoft Edge o Mozilla Firefox).
Git (opcional, para clonar el repositorio).
Instalación
Clonar el repositorio:
git clone https://github.com/usuario/veterinaria-patitas-develop.git

Copiar la carpeta del proyecto dentro del directorio:
xampp/htdocs/


Iniciar Apache y MySQL desde el panel de control de XAMPP.

Crear una base de datos en phpMyAdmin, con el nombre "veterinaria_patitas".

Importar el archivo SQL incluido en el proyecto.


Ejecución
Iniciar Apache y MySQL desde XAMPP.
Abrir un navegador web.
Acceder a la siguiente dirección:
[http://localhost/veterinaria-patitas-develop](http://localhost/proyecto-veterinaria-develop/)
El sistema estará listo para utilizarse.
